# Design Documents

These are the specifications this repository implements, kept unchanged.

| Document | Contents |
|---|---|
| [`SYSTEM_DESIGN.md`](SYSTEM_DESIGN.md) | The end-to-end system design: workbench, inference layer, agentic layer, sovereignty, deployment. The PRD and code comments call it "README" (for example "README section 4.2"). |
| [`DIAGRAMS.md`](DIAGRAMS.md) | Fifteen diagrams covering the architecture, request lifecycle, agent loop, router, inference, ledger, multimodal pipeline, knowledge base, deliverables, labels, sovereignty, demo traces and deployment. |
| [`IMPLEMENTATION_PRD.md`](IMPLEMENTATION_PRD.md) | The build plan for the agentic layer: stack, repository layout, module contracts, fixtures, phases and acceptance criteria. |

Where the implementation differs from these documents, the reason is recorded in [`../DECISIONS.md`](../DECISIONS.md).

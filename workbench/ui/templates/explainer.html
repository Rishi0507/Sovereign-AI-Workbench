How it works

An AI workbench that never leaves the refinery.

P&IDs, inspection reports, vendor negotiations and board notes cannot go to a public AI assistant. So the work is either done by hand, or pasted somewhere it should not be. This workbench runs open-weight models on MRPL's own GPU server, plans and carries out the work like an agent, and hands back real, checked deliverables. Nothing crosses the fence.

01  The problem

Confidential work has two bad options today.

Engineers either spend days copying, checking and retyping, or quietly paste sensitive material into public tools. The workbench adds a third path that stays inside the fence.

02  The architecture

Everything runs on one server, behind a firewall that drops outbound traffic.

The browser talks to the workbench on the plant LAN. The workbench talks to the models on loopback. Code runs in a container with no network. A separate monitor counts every attempt to reach the outside, and the answer on the Security page is zero.

03  Model auto-selection

Each task goes to the model that fits it, and the reason is logged.

Hard rules read the attachments and intent, a small classifier fills in the task profile, constraints remove models that cannot serve it, and a scorer picks the cheapest model whose measured quality clears the bar. A sleeping model's wake-up time counts as cost, so everyday work stays on the resident models.

04  The agent

It plans, asks, acts, checks itself, and only then hands over.

A task becomes a typed plan that the engineer approves. Each step calls a local tool, every result becomes an evidence record, and failures are retried, repaired or escalated to a stronger model. The draft is checked before anyone sees it, and approval stays locked until every issue is reviewed.

05  Reading scans and drawings

Critical fields are read twice, by OCR and by a vision model, then reconciled.

Tag numbers, dates, work orders and stamps on scanned reports and P&IDs are read independently by on-device OCR and by the vision model, which does not see the OCR answer. If they disagree, a zoomed re-read decides; if it still cannot, the field is flagged for the engineer instead of guessed.

06  Grounded in evidence

Every number in a draft points back to the page it came from.

Tools never pass raw text along. They write records into a hash-chained ledger, and the draft cites those records. On review each figure is underlined by where it came from, and a figure with no source blocks approval until someone links, corrects or confirms it.

07  Proof, not a promise

Sovereignty is measured live, from three independent sources.

The firewall drops outbound traffic by policy. On top of that, egressd reads the firewall counters, the kernel's connection table and the audit log, and any external connection turns the indicator red. A one-click self-test tries a raw IP, a DNS lookup and a connection from inside the sandbox, and shows all three being blocked.
